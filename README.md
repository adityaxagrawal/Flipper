# Flipper
2D platformer game created for school game jam with the theme 'upside down'. The core mechanic is that there are invisible 'gravity flippers' - sections of the map that reverse the direction of gravity if you move through them. You have to reach the end of the map while avoiding daedly spikes that chase after you.
Features include: character squash and stretch, coyote time, jump buffer, screen shake, dynamic camera
